Administrator bootstrap

Use backend/utils/createAdmin.js with an explicitly confirmed database name and
your own ADMIN_EMAIL and unique ADMIN_PASSWORD environment values. The password
must have at least 12 characters. This command refuses to change an existing
active administrator. Review the target database and take a backup first.

node utils/createAdmin.js --confirm-database=<exact-database-name>

No reusable password or precomputed hash is supplied. Existing accounts created
from historical example credentials require an operator-led password rotation
and session revocation before any public deployment. Do not run bootstrap or
migration commands against production as part of automated verification.
